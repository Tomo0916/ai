# AIのしくみ入門

専門学校の授業（毎週水曜日）で使う、生徒向けの教材です。
日本語・やさしい日本語・英語・ネパール語・フランス語・ミャンマー語・ベンガル語・シンハラ語・インドネシア語・ベトナム語・中国語の11言語に対応しています。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 目次ページ（全11回の日程と教材へのリンク） |
| `map.html` | 学習マップ（1ファイルで完結） |
| `lessons/06/index.html` | 第6回の読み物（体験ツール・確認クイズ付き） |
| `lessons/06/slides.html` | 第6回のスライド（← → キーで移動） |
| `lessons/06/i18n/<言語>.json` | 第6回の本文（言語ごと） |
| `assets/i18n/<言語>.json` | 画面の文言と回のタイトル（言語ごと） |
| `assets/schedule.js` | 授業日程。教材ができた回は `ready: true` にする |
| `assets/tools.js` | 体験ツール（2進数カード、文字コード、ピクセル、色、音の波） |

言語コードはSQL練習アプリと同じです（`ja` `easy` `en` `ne` `fr` `my` `bn` `si` `id` `vi` `zh`）。
やさしい日本語のふりがなは `{漢字|かんじ}` の形で書きます。

## 公開

GitHub Pages（Settings → Pages → Branch: `main` / `/ (root)`）で公開すると、
`https://tomo0916.github.io/ai/` から生徒が閲覧できます。
URLの末尾に `?lang=en` などを付けると、その言語で開きます。
